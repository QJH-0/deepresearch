## 四、执行顺序与回滚

1. 先做 2.3 工程卫生（无行为耦合，便于隔离验证）
2. 再做 2.1 四条断链（互不重叠，逐个验证）
3. 最后做 2.2 检索质量与并发（影响面最大，放最后便于定位回归）
4. 全量测试：`conda llmdev` → `python -m pytest app/test/ -q`
5. 提交：单次提交，commit message 按 `fix(<scope>): <描述>` 逐条列出

**回滚方式**：所有改动均在一次提交内，`git revert <commit>` 可整体回退。无 DDL 破坏性变更 —— `content_tsv` 为 `ADD COLUMN IF NOT EXISTS` 幂等生成列，回滚只需 `DROP COLUMN`（不影响 `content` 主数据）。
