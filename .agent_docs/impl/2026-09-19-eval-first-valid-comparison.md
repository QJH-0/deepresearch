## 怎么读这个结果

### ✅ 有正向收益

**完备性 0.9167 → 1.0**。这是 B 阶段（自适应检索 + 多轮研究）第一次在**有效对照**下
显示出可测的正向收益。同时信源质量也更好（低质占比 0.5588 → 0.4516）。

### ⚠️ 但幻觉率反向恶化

**0.0333 → 0.3**，improved 的幻觉率是 baseline 的近 9 倍。
与「信源质量更好」形成矛盾 —— 信源更好却更容易说无依据的话，需要解释。

**可能的解释（均未验证）**：
1. **轮次越多，成文时上下文越长**，模型更倾向于「补全」而非严格依据证据；
2. improved 阶段的 `deep_dive` 拿到了更多证据，摘要/综合的空间更大，
   LLM-as-Judge 判「无据」的机会随之增加；
3. **n=1 的方差** —— 单题单次，幻觉率这种 Judge 打分类指标波动本就大。

**不建议据此下结论**，更不建议据此回退 B 阶段。应当先扩大样本。

### 成本

token +27%、耗时 +14% —— 与「多跑一轮」的预期一致，属可接受范围。

## 遗留

1. **样本量 n=1** —— 除「两阶段检索可比」这一条外，所有指标差异都不足以定论。
   至少需要 5 道题。
2. **幻觉率反向恶化**需要单独跟进（先扩样本，再决定是否调 `write` 提示词）。
3. **`key_point_coverage` 仍触顶 1.0** —— Golden Set 的 `key_points` 判别力问题未解，
   这是「检索深度收益」唯一缺的判别指标（用户侧任务）。
4. 引用覆盖率 55.6% → 58.3% 的小幅变化，与
   `2026-09-19-citation-coverage-ceiling.md` 的结构性天花板结论一致。
