- **技术决策**：
  - 使用 `asyncio.wait({task}, timeout=interval)` 而非 `asyncio.wait_for`（后者超时会 cancel 内部任务，杀掉正在执行的 graph step）

  - 前端 `consumeSSE` 天然忽略 `:` 开头的注释帧，无需改动前端代码
- **遗留问题**：
  - 前端 `test_sse_heartbeat.test.ts` 待编写（需 Vitest 环境）
