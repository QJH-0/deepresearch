# R1.1 Web 搜索 Provider 链式降级

> 阶段一 · 检索链路 | 对应落地修复清单 #1：Web 搜索多级降级（SearchProvider 抽象 + 多搜索源 API 降级）
> 前置阅读：`docs/refactor/00_重构总览与执行指南.md`

## 1. 目标

在现有 DDG → SearXNG 两级降级基础上，重构为**可配置的 Provider 链**：抽象统一的 `SearchProviderChain`，按配置顺序依次尝试（ddgs → tavily → searxng），任一 Provider 成功即返回；新增 `TavilyProvider` 商用搜索兜底。全程失败时返回空列表并记 warning，不阻塞研究主流程。

**验收标准**：

- [ ] `TavilyProvider` 实现 `SearchProvider` Protocol，Tavily API 返回结果正确归一化为标准记录结构
- [ ] `SearchProviderChain` 按 `search_providers` 配置顺序链式降级，前面失败自动尝试后面
- [ ] Provider 顺序由 `config.json` 的 `search_providers` 字段驱动，无需改代码即可调整
- [ ] 所有异常（超时/限流/网络错误）均捕获为空结果，不向调用方抛异常
- [ ] 单元测试全部通过，全量回归无破坏

## 3. 详细设计

### 3.1 标准搜索结果记录（沿用现有结构，不变）

```python
{
    "source_id": "",           # 由节点层 _assign_source_ids 后分配
    "title": str,
    "url": str,
    "snippet": str,
    "domain": str,             # url 的 netloc
    "source_type": "web",
    "published_at": str,       # 可为空字符串
}
```

### 3.2 TavilyProvider（新增类，放在 `tools.py` 中 DuckDuckGoProvider 之后）

Tavily Search API：`POST https://api.tavily.com/search`

```python
class TavilyProvider:
    """Tavily 商用搜索兜底（API Key 缺失时自禁用）。"""

    def __init__(self, api_key: str | None = None, timeout: float = 10.0):
        self._api_key = (api_key or os.getenv("TAVILY_API_KEY", "")).strip()
        self._timeout = timeout

    @property
    def available(self) -> bool:
        return bool(self._api_key)

    async def search(self, query: str, max_results: int = 6) -> list[dict]:
        if not self.available:
            return []
        try:
            import httpx
            async with httpx.AsyncClient(timeout=self._timeout) as client:
                resp = await client.post(
                    "https://api.tavily.com/search",
                    json={
                        "api_key": self._api_key,
                        "query": query,
                        "max_results": max_results,
                        "search_depth": "basic",
                    },
                )
                resp.raise_for_status()
                data = resp.json()
        except Exception as exc:
            logger.warning("[tavily] 搜索失败 | query=%s | error=%s", query, exc)
            return []
        return [_normalize_web_record(
            title=r.get("title", ""),
            url=r.get("url", ""),
            snippet=r.get("content", ""),
        ) for r in (data.get("results") or [])[:max_results]]
```

### 3.3 归一化辅助函数（新增，消除三个 Provider 的重复构造逻辑）

```python
def _normalize_web_record(title: str, url: str, snippet: str) -> dict:
    return {
        "source_id": "",
        "title": title,
        "url": url,
        "snippet": snippet,
        "domain": urllib.parse.urlparse(url).netloc if url else "",
        "source_type": "web",
        "published_at": "",
    }
```

`DuckDuckGoProvider.search` 与 `_searxng_search_records` 中的记录构造改用此函数（`_searxng_search_records` 顺便保持同步实现，由调用方 `asyncio.to_thread` 包装，见 3.4）。

### 3.4 SearchProviderChain（新增链式管理器）

```python
class SearchProviderChain:
    """按注册顺序链式降级：任一 Provider 返回非空结果即短路返回。"""

    def __init__(self, providers: list):
        # 过滤掉 available=False 的 Provider（如未配置 API Key 的 Tavily）
        self._providers = [p for p in providers if getattr(p, "available", True)]

    async def search(self, query: str, max_results: int = 6) -> list[dict]:
        for provider in self._providers:
            try:
                records = await provider.search(query, max_results=max_results)
            except Exception as exc:
                logger.warning("[search-chain] %s 异常 | query=%s | error=%s",
                               type(provider).__name__, query, exc)
                records = []
            if records:
                return records
            logger.info("[search-chain] %s 无结果，尝试下一 Provider", type(provider).__name__)
        logger.warning("[search-chain] 所有搜索源均未返回结果 | query=%s", query)
        return []
```

### 3.5 SearXNG 改造为 Provider 类

将 `_searxng_search_records()` 重构为 `SearXNGProvider` 类（实现 `SearchProvider` Protocol）：

- `__init__(self, base_url: str | None, timeout: float = 10.0)`：base_url 来自 `SEARX_URL` 环境变量
- `available` 属性：`bool(self._base_url)`
- `search()` 内部逻辑不变（urllib 请求 + JSON 解析），但整体包一层 `asyncio.to_thread(self._search_sync, query, max_results)` 转异步，异常捕获返回 `[]`
- 结果构造改用 `_normalize_web_record`

### 3.6 全局链构建与入口改造

```python
_PROVIDER_CHAIN: SearchProviderChain | None = None

def _get_provider_chain() -> SearchProviderChain:
    """按 config.json 的 search_providers 顺序构建全局链（惰性单例）。"""
    global _PROVIDER_CHAIN
    if _PROVIDER_CHAIN is None:
        order = _load_search_provider_order()   # 见 3.7，读取失败回退默认 ["ddgs", "searxng"]
        factories = {
            "ddgs": lambda: _get_ddg_provider(),
            "tavily": lambda: TavilyProvider(),
            "searxng": lambda: SearXNGProvider(os.getenv("SEARX_URL", "").strip()),
        }
        providers = [factories[name]() for name in order if name in factories]
        _PROVIDER_CHAIN = SearchProviderChain(providers)
    return _PROVIDER_CHAIN


async def web_search_records(query: str, count: int = 5) -> list[dict]:
    return await _get_provider_chain().search(query, max_results=count)
```

注意：`web_search_records` 当前为同步函数（探索确认签名 `def web_search_records(query, count=5)`，内部调用同步 DDG）。**保持函数签名同步不变**（调用方 `web_search.py` 节点以同步方式使用），链式调用内部用 `asyncio.run` 不允许（可能在事件循环内）——采用方案：`web_search_records` 保持同步外壳，内部通过 `asyncio.get_event_loop()` 判断：

```python
def web_search_records(query: str, count: int = 5) -> list[dict]:
    chain = _get_provider_chain()
    try:
        loop = asyncio.get_running_loop()
    except RuntimeError:
        loop = None
    if loop is not None:
        # 已在事件循环中：把整条链跑进线程池（链内部是异步实现）
        return asyncio.run_coroutine_threadsafe(
            chain.search(query, max_results=count), _get_chain_loop()
        ).result(timeout=60)
    return asyncio.run(chain.search(query, max_results=count))
```

其中 `_get_chain_loop()` 维护一个专用的后台事件循环线程（daemon thread + `asyncio.new_event_loop()`），在模块首次使用时启动。若探索发现 `web_search_records` 实际已是 async 或调用方为 async 上下文，直接简化为 `async def` 并同步修改调用方——**以实际代码为准**，在执行日志中记录实际选择。


```python
search_providers: list[str] = Field(default_factory=lambda: ["ddgs", "searxng"])
```
