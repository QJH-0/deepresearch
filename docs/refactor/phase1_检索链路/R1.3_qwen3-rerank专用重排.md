# R1.3 qwen3-rerank 专用重排模型

> 阶段一 · 检索链路 | 对应落地修复清单 #3：将 LLM-as-reranker 换为 DashScope qwen3-rerank API，保留 LLM 查询改写
> 前置阅读：`docs/refactor/00_重构总览与执行指南.md`

## 1. 目标

将本地知识库重排从 **LLM-as-reranker**（qwen-plus 生成式排序，延迟高、输出解析脆弱）升级为 **DashScope 专用重排 API（qwen3-rerank）**，判别式单次推理完成 pair 评分。保留现有 `LLMReranker` 作为 API 失败时的降级路径。

**验收标准**：

- [ ] `DashScopeReranker` 调用 DashScope 文本重排 API（模型 `gte-rerank` 或 `qwen3-rerank`，以 DashScope 当前文档为准），输入 query + 候选文档列表，返回按相关性排序的 top-k 文档
- [ ] `RAGConfig` 增加 `rerank_model`（默认 `qwen3-rerank`）与 `enable_rerank_model`（默认 `True`）开关
- [ ] API 调用失败（网络/限流/Key 无效/模型不存在）时自动降级 `LLMReranker`，主流程不报错
- [ ] 重排输入做长度与数量截断保护（单文档截断至 2000 字符、候选上限 20 条），避免超 token 上限
- [ ] 单元测试全部通过，全量回归无破坏

## 3. 详细设计

### 3.1 技术选型与调用方式

DashScope 文本重排 API（OpenAI 兼容模式**不支持** rerank，必须用以下二选一）：

**方案 A（推荐）：dashscope SDK**

```
pip install dashscope   # requirements.txt 追加 dashscope>=1.20
```

```python
import dashscope
dashscope.api_key = api_key

resp = dashscope.TextReRank.call(
    model=self._model,             # "qwen3-rerank"（若不可用回退 "gte-rerank"，见 3.4 降级链）
    query=query,
    documents=[doc.page_content for doc in documents],
    top_n=top_k,
    return_documents=False,
)
# resp.status_code == "OK" / HTTPStatusCode 200
# resp.output.results: [{index: 0, relevance_score: 0.97}, ...] 按 relevance_score 降序
```

**方案 B（备选）：直接 HTTP**（若 dashscope SDK 安装受限）

```
POST https://dashscope.aliyuncs.com/api/v1/services/rerank/text-rerank/text-rerank
Headers: Authorization: Bearer {DASHSCOPE_API_KEY}
Body: {"model": "...", "input": {"query": "...", "documents": ["...", "..."]}, "parameters": {"return_documents": false, "top_n": k}}
```

执行时先在沙箱验证 SDK 可用性，选 A 不可行再走 B；把实际选择记入执行日志。

**执行前必做**：用 WebSearch 或 DashScope 官方文档确认当前可用的 rerank 模型名（`qwen3-rerank` / `gte-rerank`）与请求格式，以官方文档为准，本文档接口签名仅作参考。

### 3.2 DashScopeReranker（新增类，放在 LLMReranker 之后）

```python
class DashScopeReranker:
    """DashScope 专用重排模型（qwen3-rerank）。失败时由上层降级 LLMReranker。"""

    MAX_DOCS = 20          # 候选数量上限
    MAX_DOC_CHARS = 2000   # 单文档截断长度

    def __init__(self, api_key: str, model: str = "qwen3-rerank", timeout: float = 15.0):
        self._api_key = api_key
        self._model = model
        self._timeout = timeout

    def rerank(self, query: str, documents: list, top_k: int = 5) -> list:
        """同步实现；调用方（search_records 为 async）用 asyncio.to_thread 包装。"""
        docs = documents[: self.MAX_DOCS]
        texts = [d.page_content[: self.MAX_DOC_CHARS] for d in docs]
        # —— dashscope.TextReRank.call，见 3.1 ——
        # 失败（网络异常 / status_code != 200 / results 为空）→ raise RerankUnavailable(...)
        # 成功 → 按 output.results 的 index 顺序映射回 Document 列表，截断 top_k
```

关键实现点：

- 返回 `results` 中每个元素带 `index`（指向输入 documents 下标）与 `relevance_score`；按 `index` 映射回原 `Document` 对象
- 自定义异常 `class RerankUnavailable(RuntimeError)`，与「结果为空」区分：**异常 → 降级 LLMReranker；正常但零结果 → 返回空列表**（空列表不降级，属于「确实都不相关」）
- SDK 调用包 `try/except Exception` 统一转 `RerankUnavailable`

### 3.3 RAGSystem 接线

```python
# RAGConfig 新增：
rerank_model: str = "qwen3-rerank"
enable_rerank_model: bool = True

# __init__ 中：
self.reranker_model = (
    DashScopeReranker(api_key, model=self.config.rerank_model)
    if self.config.enable_rerank_model and api_key
    else None
)

# search_records 中重排分支改为：
if self.config.enable_reranker and len(merged_docs) > k * 2:
    reranked_docs = await self._rerank(query, merged_docs, top_k=k * 2)

async def _rerank(self, query, documents, top_k):
    if self.reranker_model is not None:
        try:
            return await asyncio.to_thread(
                self.reranker_model.rerank, query, documents, top_k
            )
        except RerankUnavailable as exc:
            logger.warning("[rag] 专用重排失败，降级 LLM 重排 | %s", exc)
    if self.reranker is not None:
        return await asyncio.to_thread(self.reranker.rerank, query, documents, top_k)
    return documents[:top_k]
```

注意：`LLMReranker.rerank` 当前为同步调用，接线时统一 `asyncio.to_thread` 包装（确认其 LLM invoke 为同步阻塞）。api_key 来源与 `QueryRewriter` 一致（先读 `RAGSystem.__init__` 确认现有 api_key 传参链）。

### 3.4 配置与降级链

```
rerank 降级链：DashScopeReranker(qwen3-rerank)
              → DashScopeReranker(gte-rerank)（仅当 qwen3-rerank 报「模型不存在」类错误时，作为模型名回退，一次进程内记忆）
              → LLMReranker（qwen-plus 生成式排序）
              → 不重排，直接截断
```

`config.json` 增加：

```json
{
  "rerank_model": "qwen3-rerank",
  "enable_rerank_model": true
}
```

`BusinessSettings` 同步增加两个可选字段。
