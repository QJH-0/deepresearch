# R3.3 PDF 导出管线（Playwright headless Chromium）

> 阶段三 · 可靠性与运维 | 对应落地修复清单 #9：替换 weasyprint 降级方案为 Playwright headless Chromium print-to-pdf
> 前置阅读：`docs/refactor/00_重构总览与执行指南.md`

## 1. 目标

将报告 PDF 导出从 **weasyprint**（Windows 环境缺系统库、中文/公式排版受限、现有代码自带 ImportError 降级到「HTML 打印页」）替换为 **Playwright headless Chromium print-to-pdf**：后端渲染完整 HTML（含 CSS 排版、代码高亮、表格），调用浏览器引擎生成 PDF，排版保真度高、跨平台一致。

**验收标准**：

- [ ] `GET /threads/{thread_id}/export/pdf` 使用 Playwright Chromium 生成 PDF
- [ ] 报告 HTML 模板：中文正文（思源黑体/Noto Sans SC 兜底）、标题分级、代码块等宽字体、表格边框、页眉页脚（页码）
- [ ] 生成超时保护（默认 30s）与异常降级链：Playwright 失败 → 返回 Markdown 文件（明确 Content-Disposition 提示），不再走旧 weasyprint 路径
- [ ] 无报告内容时维持现有 404 行为
- [ ] `requirements.txt` 移除 weasyprint、新增 playwright；提供 `playwright install chromium` 安装说明（README 或脚本）
- [ ] Docker 镜像可运行（Dockerfile 更新，若 playwright 系统依赖在镜像内缺失则补安装）
- [ ] 单元测试全部通过（Playwright 调用 mock），全量回归无破坏

## 3. 详细设计

### 3.1 PDF 服务（新增 `app/backend/service/pdf_export_service.py`）

```python
class PdfExportService:
    """Playwright headless Chromium 报告导出。"""

    TIMEOUT_SECONDS = 30.0

    async def export(self, report_html: str) -> bytes:
        """渲染 HTML 为 PDF。任何异常向上抛出，由 router 层降级。"""
        from playwright.async_api import async_playwright
        async with async_playwright() as p:
            browser = await p.chromium.launch(headless=True)
            try:
                page = await browser.new_page()
                await page.set_content(report_html, wait_until="load")
                pdf = await page.pdf(
                    format="A4",
                    margin={"top": "20mm", "bottom": "20mm", "left": "15mm", "right": "15mm"},
                    print_background=True,
                    display_header_footer=True,
                    header_template="<span></span>",                        # 页眉留空（报告标题在正文内）
                    footer_template=(
                        '<div style="font-size:8px; width:100%; text-align:center; color:#888;">'
                        f'第 <span class="pageNumber"></span> 页 / 共 <span class="totalPages"></span> 页'
                        "</div>"
                    ),
                )
                return pdf
            finally:
                await browser.close()
```

浏览器实例策略：**每次导出新建 browser**（导出是低频操作，简化生命周期管理；若实测启动开销不可接受，再改为进程级单例 browser + 并发锁——先简单后优化，决策记执行日志）。

### 3.3 router 改造（export_pdf）

```python
@router.get("/threads/{thread_id}/export/pdf")
async def export_pdf(thread_id: str):
    report_md = ...                                    # 现有取报告正文逻辑不变
    if not report_md:
        raise HTTPException(404, ...)                  # 现有行为不变

    service = get_pdf_export_service()
    try:
        pdf_bytes = await service.export(render_report_html(report_md))
        return Response(
            content=pdf_bytes,
            media_type="application/pdf",
            headers={"Content-Disposition": f'attachment; filename="report_{thread_id[:12]}.pdf"'},
        )
    except Exception as exc:
        logger.error("[export] PDF 生成失败，降级 Markdown | thread=%s | %s", thread_id, exc)
        # 降级：返回 Markdown 文件（保内容不保排版），不再走 HTML 打印页
        return Response(
            content=report_md,
            media_type="text/markdown",
            headers={"Content-Disposition": f'attachment; filename="report_{thread_id[:12]}.md"'},
        )
```

## 6. 风险与回滚

- **风险 1**：Chromium 下载体积与容器镜像膨胀（+300~400MB）。缓解：Dockerfile 中只装 chromium 不装全家桶；接受镜像变大（导出保真度收益对价）。
- **风险 2**：服务器无外网时 `playwright install` 失败。缓解：文档提供离线包说明；运行期降级链保证导出接口仍可用（返回 md）。
- **风险 3**：并发导出多个大报告时内存峰值。缓解：低频操作 + 每次独立 browser 用完即关；如需进一步保护加 asyncio.Lock 串行化（导出低频，可接受）。
- **回滚**：revert 后 weasyprint 依赖已删——回滚时需同时恢复 requirements 中 weasyprint 行（记录在 commit message 中提醒）；或保留 weasyprint 依赖一个版本周期，确认稳定后再删（推荐后者，执行时二选一并记录）。
