# DeepResearch 代码审计报告

> 审计基准：`docs/dev/`（README + Phase0~Phase8 契约 + 存储与消息中间件选型）
> 审计范围：`app/backend/`、`app/mult_agents/`、`agent_front/src/`
> 审计日期：2026-09-03
> 审计方法：逐 Phase 契约对照 + `file:line` 锚点 + 验收清单勾选

## 1. 执行摘要

**总体结论**：Phase0（事件协议）、Phase2（流式重写核心）、Phase3（取消/恢复）、Phase5（langmem 记忆）**落地质量较高**；但 **Phase1（State 重构）完全未执行**、**Phase4（HITL）存在 2 处 P0 级全链路失效**、**Phase7（引用溯源/导出）存在前后端字段级不匹配**、**Phase0/P2 的"删除旧服务"纪律未兑现**（`workflow_service.py` 仍存活并被路由引用）。

按优先级统计：**P0（阻断）4 项、P1（重要）5 项、P2（次要）6 项**。其中 3 处问题会导致用户可感知的功能失效（HITL 审批/澄清/报告审核无法恢复、历史回滚失效），建议在进入下一轮迭代前优先修复。

## 4. 修复建议（按优先级，含回归保护）

### P0 修复（先做）

1. **P0-1 修复 HITL resume payload**
   - 前端三种卡片 emit 统一补 `kind` 字段：
     - `PlanApprovalCard` → `{kind:'plan_approval', action, reason?}`
     - `ClarifyCard` → `{kind:'clarification', answers:[...]}`（"跳过"改为 `{kind:'clarification', answers:['']}`）
     - `ReportReviewCard` → `{kind:'report_review', action:'adopt'|'deepen', extra_sub_questions?}`（`accept`→`adopt`，删除 `reject`）
   - 回归保护：`test_hitl.py` 增加"卡片 payload 结构与后端 schema 一致性"契约测试（用后端 `PlanApprovalResumePayload` 等 schema 直接反序列化前端样例 payload）。

2. **P0-2 修复 analyze_clarify interrupt**
   - `analyze.py:62` 改用 `from ._shared import raise_interrupt`，payload 携带 `kind:"clarification"`；若需保留缺口信息，放入 `payload` 内（如 `payload={"questions":[...]}`），不再用 `type:"analyze_clarify"`。
   - 回归保护：`test_stream_events.py` 增加"interrupt.raised 的 kind 必须落在三枚举内"的断言，覆盖 analyze 分支。

3. **P0-3 删除旧服务**
   - 将 `workflow_service.py` 仍被依赖的职责（`list_threads`/`get_thread_messages`/`get_state_history`/`update_state`）迁移至 `research_service.py` 或独立 `thread_service`，随后删除 `workflow_service.py`，清理 `research_router.py` 中 `WorkflowService`/`get_workflow_service` 的 import 与依赖注入。

4. **P0-4 修复回滚前后端契约**
   - 前端 `fetchHistory` 适配后端 `{history:[{checkpoint_id, next, created_at, interrupts_count}]}`；`rollbackThread` 改为发 `{thread_id, values, as_node}`（或后端新增 `checkpoint_id` 恢复语义）。先与用户确认回滚的期望语义（恢复 checkpoint vs 覆盖 state 值）再定契约。

### P1 修复（随后）

- **P1-1**：按 P1 字段迁移规则表重构 `state.py`（大改动，建议单独立项 + 全量迁移测试）。
- **P1-2**：`models.py` 切换到 `init_chat_model`。
- **P1-3**：`interrupt.ts` 增加 `rebuild(threadId)`，调 `GET /threads/{id}/interrupt` 重建。
- **P1-4**：统一动作枚举（随 P0-1 一并改）。
- **P1-5**：统一引用 ID 为 `[n]` 或更新 P7 文档承认 `[WEB1_1-1]` 格式（二选一，避免规则漂移）。

### P2 修复（收尾）

- `requirements.txt` 补 `weasyprint`；`ChatView.vue` 压缩行数；`_stream_with_registry` 走 `registry.register()`；`utils/sse.ts` 删除；`memory_service` namespace 一致性确认。
