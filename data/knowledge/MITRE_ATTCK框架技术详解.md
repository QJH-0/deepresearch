# MITRE ATT&CK 框架技术详解

## 1. 概述

MITRE ATT&CK (Adversarial Tactics, Techniques, and Common Knowledge) 是一个全球可访问的对抗战术和技术知识库，基于真实世界的观察。ATT&CK 框架是网络威胁情报 (CTI) 领域的事实标准。

### 1.1 历史背景

- 由 MITRE 公司于 2013 年创建
- 最初来源于对 APT（高级持续性威胁）组织的攻击行为分析
- 基于 REAL-TECH 项目发展而来
- 2015 年首次公开发布

### 1.2 框架结构

ATT&CK 矩阵按照以下层级组织：

- **战术 (Tactics)**: 攻击者的目标，即"做什么"
- **技术 (Techniques)**: 实现战术的具体方法，即"怎么做"
- **子技术 (Sub-techniques)**: 技术的更细粒度描述
- **程序 (Procedures)**: 特定威胁组织使用的具体实现

## 2. 14 种战术类别

### 2.1 侦察 (Reconnaissance, TA0043)

攻击者在攻击前收集信息阶段：

- 主动扫描 (T1595)
- 搜索公开数据库 (T1592)
- 搜索受害者拥有的网站 (T1594)
- 钓鱼式信息收集 (T1593)

### 2.2 资源开发 (Resource Development, TA0042)

攻击者建立攻击基础设施：

- 获取基础设施 (T1583)
- 创建账户 (T1136)
- 获取能力 (T1587)
- 开发能力 (T1588)

### 2.3 初始访问 (Initial Access, TA0001)

攻击者获得对目标网络的初始入口：

- 鱼叉式钓鱼 (T1566)
- 有效性攻击 (T1110)
- 外部远程服务 (T1133)
- 硬件攻击 (T1200)

### 2.4 执行 (Execution, TA0002)

在目标系统上运行恶意代码：

- 命令和脚本解释器 (T1059)
- 容器管理命令 (T1610)
- 部署和运行软件 (T1653)
- 利用客户端执行 (T1203)

### 2.5 持久化 (Persistence, TA0003)

攻击者维持在系统中的访问权限：

- 计划任务/作业 (T1053)
- 启动或登录自动执行 (T1547)
- 账户操作 (T1098)
- 创建或修改系统进程 (T1543)

### 2.6 权限提升 (Privilege Escalation, TA0004)

攻击者获取更高级别权限：

- 访问令牌操作 (T1134)
- 滥用特权控制 (T1078)
- 进程注入 (T1055)

### 2.7 防御规避 (Defense Evasion, TA0005)

攻击者避免被检测到：

- 混淆文件或信息 (T1027)
- 伪装 (T1036)
- 签名代码 (T1027)
- 禁用安全工具 (T1562)

### 2.8 凭据访问 (Credential Access, TA0006)

攻击者获取系统凭据：

- 暴力破解 (T1110)
- 凭据提取 (T1555)
- 密码策略发现 (T1209)
- 网络凭据提取 (T1040)

### 2.9 发现 (Discovery, TA0007)

攻击者了解系统和网络环境：

- 系统信息发现 (T1082)
- 网络服务发现 (T1046)
- 文件和目录发现 (T1083)
- 账户发现 (T1087)

### 2.10 横向移动 (Lateral Movement, TA0008)

攻击者在网络中移动：

- 远程服务 (T1021)
- 横向工具传输 (T1570)
- 内部鱼叉式钓鱼 (T1534)
- 传递票据 (T1550)

### 2.11 收集 (Collection, TA0009)

攻击者收集目标数据：

- 数据暂存 (T1005)
- 剪贴板数据 (T1115)
- 屏幕截图 (T1113)
- 音频捕获 (T1123)

### 2.12 命令与控制 (Command and Control, TA0011)

攻击者与受感染系统通信：

- 应用层协议 (T1071)
- 数据编码 (T1132)
- 代理 (T1090)
- 加密通道 (T1573)

### 2.13 数据外传 (Exfiltration, TA0010)

攻击者将数据从目标网络传输到外部：

- 通过 C2 通道外传 (T1041)
- 通过替代协议外传 (T1048)
- 通过 Web 服务外传 (T1567)
- 物理外传 (T1052)

### 2.14 影响 (Impact, TA0040)

攻击者破坏或操纵业务运营：

- 数据销毁 (T1485)
- 数据加密以造成影响 (T1486)
- 系统关机/重启 (T1529)
- 资源劫持 (T1496)

## 3. ATT&CK Navigator

ATT&CK Navigator 是一个 Web 应用程序，允许用户浏览 ATT&CK 矩阵并注释战术和技术。安全团队可以使用它来：

- 可视化防御覆盖范围
- 识别攻击面
- 规划检测和缓解策略
- 与其他安全团队共享分析结果

## 4. 实战应用

### 4.1 威胁建模

使用 ATT&CK 框架可以：

1. 识别特定 APT 组织的 TTP（战术、技术和程序）
2. 评估组织对这些攻击的防御覆盖
3. 制定针对性的检测规则
4. 优先处理高风险攻击路径

### 4.2 检测工程

- 基于 ATT&CK 技术编写 Sigma 规则
- 使用 MITRE CAR (Cyber Analytics Repository) 检测分析
- 集成 SIEM 平台进行自动化检测

### 4.3 红队评估

- 使用 ATT&CK 模拟计划进行红队测试
- 评估蓝队检测能力
- 识别防御盲点
